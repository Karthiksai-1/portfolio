# Personal Engineering Portfolio

A minimalist, editorial portfolio website showcasing production RAG systems, LLM evaluation pipelines, and enterprise data analytics projects.

## Tech Stack
- **Framework:** React + Vite (TypeScript)
- **Styling:** Tailwind CSS
- **Routing:** React Router v6
- **Deployment:** Vercel

## Project Structure
- `/` — Core engineering portfolio (experience, proof metrics, featured systems, education, contact)
- `/projects/:slug` — Deep-dive technical case study routes with system architecture schemas and trade-off analyses
